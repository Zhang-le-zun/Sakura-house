# 桜日和 · 樱花水岸小屋

一座可随时间流转的 Three.js 樱花水岸茶庭微缩模型。所有模型、纹理与动画均为程序化生成，不需要构建，也不需要联网。

## 直接运行

双击 **index.html** 即可。推荐使用现代 Chrome、Edge、Safari 或 Firefox。

如果浏览器对本地脚本有限制，也可以在本目录打开终端运行：

    python -m http.server 8080

然后访问 http://127.0.0.1:8080/ 。

## 操作

- 拖动：环绕旋转
- 滚轮 / 双指捏合：缩放
- 点击障子：开合木门
- 点击水面：落下一圈涟漪
- 点击风铃：拨动一次
- 07:00 / 18:00 / 22:00：切换清晨、黄昏、夜晚
- 底部细线滑杆：连续调节时间
- 纯享模式：隐藏界面；按 Esc 或右上角小按钮退出

## 实现摘要

- Three.js 0.160.0（本地 vendor，经典 UMD 构建，支持直接打开 file://）
- 程序化 CanvasTexture：木纹、瓦面、灰泥、榻榻米、和纸、石材、苔藓、花瓣、挂轴、挂签
- 使用 InstancedMesh 承载瓦片、花簇、草叶、落樱与水中花瓣
- 自定义水面 shader：多层细波、菲涅尔、半帧率平面反射、程序化碎光与涟漪
- 时间系统在 07:00 / 18:00 / 22:00 三个锚点间连续插值，统一驱动背景、光向、亮度、室内灯、水色与 CSS 色板
- 静态网格按材质自动合批；桌面最高 DPR 2，移动端 DPR 1.5；支持减少动态偏好

## 兼容与性能

页面需要 WebGL。无法创建 WebGL 上下文时会显示提示，不会留白。移动端加载时会自动减少花簇与阴影分辨率，并降低反射渲染频率。
